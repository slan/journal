# journal

Raw voice-session summaries, one file per session, one commit per file, written by the claude.ai **Journaling** project. Files are `YYYY-MM-DD-<slug>.md` at the root. Nothing here is edited after landing.

Consumed by the hub repo (`~/src/claude`) as the `inbox/` submodule; its `/inbox` skill files entries into journal, ideas, and projects and records progress as the submodule pointer.
